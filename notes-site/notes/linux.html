一、常用命令：六大族速查

按"做什么"分族：进程/防火墙/端口/软件/目录/文件。

Linux 命令按"做什么"分成六族，先认族再记命令，避免孤立背诵。

族命令作用记忆画面
进程ps -ef | grep ssh查看进程户籍警：列出所有住户
进程kill -9 7143强杀进程暴力拆迁：-9 不给善后
防火墙systemctl status firewalld查防火墙状态门卫查岗
防火墙systemctl stop firewalld关防火墙门卫下班
防火墙systemctl start firewalld开防火墙门卫上班
端口netstat -tlunp查看监听端口港口调度：看哪些码头在用
端口curl http://www.baidu.com模拟发送请求试探电话：拨一下看通不通
软件rpm -qa | grep java查软件安装路径查仓库账本
软件which java查命令所在路径问路：java 在哪
系统poweroff / reboot关机 / 重启总闸：拉电 vs 重启
编辑vi / vim编辑文件i 进编辑，ESC 退

补充：kill -9 是强制终止（SIGKILL，进程来不及清理资源），kill -15（默认）是优雅终止（SIGTERM，进程可做善后）。生产环境优先用 kill -15，只有进程卡死无响应才上 kill -9。

二、常见目录：七个关键文件夹

root/bin/boot/etc/home/usr/opt 各司其职。

Linux 一切皆文件，目录有固定职责。记住七个关键目录，找配置/命令/软件不迷路。

目录作用记忆画面
/root系统管理员 Home 目录老板办公室：root 的家
/bin经常使用的命令工具箱：常用工具随手拿
/boot启动 Linux 时的核心文件引擎舱：开机要用的核心
/etc系统管理配置文件和子目录配置档案室
/home普通用户 Home 目录员工宿舍：普通用户的家
/usr默认安装软件的目录默认仓库：软件默认装这
/opt主机额外安装软件的目录额外仓库：第三方软件装这

补充：/usr 是系统自带软件默认安装目录（如 yum 装的），/opt 是用户额外安装的第三方软件目录（如自己解压的 JDK/Tomcat）。自己装的软件放 /opt，包管理器装的在 /usr。

三、六大查日志技巧：日志排查核心

实时/上下文/时间范围/翻页/统计/动态六种打法。

日志排查是后端最高频操作。六个技巧按场景分类，遇到问题对号入座。

编号场景命令记忆画面
①实时看关键字tail -fn 10 clp-riskroute.log | grep 关键字监听电台：实时跟新
②关键字附近几行cat clp-riskroute.log | grep -C 5 关键字看上下文：前后 5 行
③时间范围内关键字sed -n '/2023-04-24 14:59:05,914/,/2023-04-24 14:59:07,548/p' clp-riskroute.log | grep 关键字时间切片：只看这一段
④less 翻页搜索less clp-riskroute.log → shift+G 到尾部 → ?关键字 向上 / /关键字 向下，按 n 继续翻书：跳到尾，前后搜
⑤统计关键字数量zgrep 关键字 clp-riskroute.2023-04-24.69.log.zip | wc -l数人头：报错出现几次
⑥动态/翻页/行号tail -f a.txt 动态 / more a.txt 翻页 / nl a.txt 带行号三种看法：跟/翻/编号

补充：tail -f 是实时跟踪（文件增长就显示），more 是一次性翻页（不能实时）；查实时日志用 tail -f，看历史大文件用 more 或 less。grep -C 5 显示前后各 5 行，grep -A 5 只显示后 5 行，grep -B 5 只显示前 5 行（C=Context, A=After, B=Before）。less 里 ?关键字 向上搜，/关键字 向下搜，方向别搞反。zgrep 直接搜压缩包内容，不用先解压。

四、基本命令：路径与用户

pwd 报坐标、cd 导航、ll/ls 列文件、su 切用户。

命令作用记忆画面
ipconfig查看 IP 地址查门牌号
su更换用户换身份
pwd打印当前路径我在哪：报当前坐标
cd ..返回上级文件夹退一层
cd /返回根路径回到根
ll / ls打印所有路径列清单
ls -al含隐藏文件全部列出透视：连隐藏的也看

补充：ll 是 ls -l 的别名（部分发行版），显示详细信息（权限/属主/大小/时间）；ls 只列文件名。ls -al 的 -a 显示隐藏文件（以 . 开头），-l 显示长格式。Linux 查 IP 实际多用 ip addr 或 ifconfig，原文 ipconfig 是 Windows 命令。

五、文件夹与文件操作：增删改移拷

mkdir/touch/mv/rm/cp 五件套，rm -rf 最危险。

操作命令作用记忆画面
建文件夹mkdir demo创建文件夹盖新房
建文件touch a.txt新建空文件拿张白纸
移动mv a.txt /usr/local/test/移动文件搬家
删文件rm a.txt删除文件扔掉
删文件夹rm -r递归删文件夹连锅端
强制删rm -rf强制递归删推土机：不问直接推
拷贝cp a.txt /usr/local/demo复制文件复印一份

补充：rm -r 是递归删（会逐个问确认），rm -rf 是强制递归删（-f 不问直接删）。-r=recursive，-f=force。mv 既能移动也能重命名：mv a.txt b.txt 同目录下就是改名。绝对禁忌：rm -rf / 会删整个系统，生产环境永远先 pwd 确认路径再执行 rm -rf，最好用绝对路径且 Tab 补全避免误删。

六、vim 编辑器：三模式与快捷键

一般/编辑/底行三模式，:wq 存退 :q! 弃退。

vim 有三个模式：一般模式、编辑模式、底行模式。模式切换是 vim 入门第一关，搞错模式所有按键都乱套。

模式进入方式作用记忆画面
一般模式vim a.txt 默认进入移动/复制/粘贴/删除待命状态
编辑模式一般模式按 i输入文字动笔写
底行模式编辑模式按 ESC 再按 :保存/退出/定位/设置下指令

保存退出四件套：:wq 保存退出、:q! 不保存强制退出、:set number 显示行数、:n 定位到第 n 行。

一般模式快捷键：yy 复制一行、p 粘贴、gg 第一行、G 最后一行、u 撤销（编辑模式）、ctrl+r 反撤销（编辑模式）。

补充：:wq 是保存退出，:q! 是不保存强制退出（改动丢弃），:q 是未改动时退出（有改动会报错）。i 在光标前插入，a 在光标后插入，o 下方新开一行，O 上方新开一行。gg 是第一行（两个 g），G 是最后一行（大写 G），大小写含义不同别按错。

七、chmod 授权：三位数字读懂权限

r=4 w=2 x=1 相加，三位=所有者/同组/其他。

chmod 用三位数字表示权限：所有者/同组/其他各一位，每位是 r(4)+w(2)+x(1) 的和。看懂数字就懂权限。

命令数字拆解含义记忆画面
chmod 700 文件名7=4+2+1 / 0 / 0当前用户读写执行，同组和其他无任何权限私人保险箱
chmod 666 文件名6=4+2 / 6 / 6所有组均有读写权限，无执行公告栏：能看能写不能跑
chmod 777 文件名7 / 7 / 7最高权限，所有人读写执行大门敞开
chmod -R 777 目录递归同时授予目录下所有子文件全楼授权

权限数字对照：7=rwx（读+写+执行）、6=rw-（读+写）、5=r-x（读+执行）、4=r--（只读）、0=---（无任何权限）。

补充：r=4、w=2、x=1，权限数字是三者相加。三位数字顺序是所有者/同组用户/其他用户，不是"读/写/执行"。-R 是递归（大写 R），对目录下所有子文件子目录都生效；不加 -R 只改当前目录本身。生产禁忌：chmod 777 是最大权限，安全隐患极大，生产环境绝不用；按需给最小权限（如 750）。

八、高频场景题

日志定位/端口占用/防火墙排查三连。

"线上日志报错，怎么快速定位？"

先 tail -fn 200 app.log | grep ERROR 实时跟关键字；要上下文用 grep -C 10 ERROR app.log 看前后 10 行；要按时间范围用 sed -n '/开始时间/,/结束时间/p' app.log | grep 关键字 切片；大文件用 less 翻页，shift+G 跳尾部，?关键字 向上 /关键字 向下搜；要统计报错次数用 zgrep ERROR app.log.zip | wc -l（压缩包直接搜）。

"端口被占用，怎么查是谁占的？"

netstat -tlunp | grep 端口号 查看该端口被哪个进程占用（最后一列是 PID/程序名），再用 ps -ef | grep PID 确认进程详情，确认无用后 kill -9 PID 释放。-t TCP、-l 监听、-u UDP、-n 显示数字端口、-p 显示进程。

"防火墙挡了服务访问，怎么排查？"

先 systemctl status firewalld 看防火墙是否在运行；在运行则 systemctl stop firewalld 临时关闭验证是否防火墙问题；确认后用 curl http://目标IP:端口 测试连通性。生产环境不建议直接关防火墙，应放行指定端口（firewall-cmd --add-port=8080/tcp --permanent + --reload）。

九、面试回答模板

问题本质 → 排查路径 → 根因与方案，三句话讲清。

问题本质是……（先说场景：日志排查/端口占用/防火墙/权限）。

我的排查路径是……（命令 + 动作 + 看什么），因为……（为什么这个命令适合这个场景）。

根因是……，处理方案是……（命令修复 / 配置调整 / 权限收敛）。

例：问"线上日志怎么查"——本质是从海量日志里快速定位关键字；排查路径是先 tail -f | grep 实时跟，要上下文用 grep -C，要时间范围用 sed -n 切片，因为不同场景用不同工具效率最高；根因定位后处理方案是修代码或调配置，日志只是证据不是终点。
